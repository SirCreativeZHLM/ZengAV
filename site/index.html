Two commands. Nothing running in the background.

ZengAV is an open-source antivirus for macOS, Windows and Linux. scan checks the whole computer. check looks at the files or folders you pick. When it finds something, you decide: delete it, accept it, or skip it.

Download ZengAV Read the source
$ zengav check ~/Downloads Scanned 412 files (0 unchanged skipped, 0 unreadable) 1 threat(s) found: ~/Downloads/eicar.com [275a021bbfb6] known malware hash ~/Downloads/eicar.com -> [d]elete, [a]ccept (never flag again), [s]kip?

The output format is real. The folder and file count are an example, and eicar.com is the industry-standard harmless test file that every antivirus is meant to flag.

Only the two things you actually do

There is no dashboard, tray icon, scheduler or account. You run a command, read the result, and it exits.

scan

Walks every drive on the computer, skipping system pseudo-files that hold nothing to scan.

zengav scan
--update
Fetch the newest malware hashes and rules first.
--heuristics
Also report weak signals, like packed programs in temp folders.
--full
Ignore the unchanged-file cache and rescan everything.

check

Scans only what you name: one file, several, or whole folders. Use it on a download before you open it.

zengav check <path>...
--report-only
Show findings and never ask. Good for scripts.
--delete
Delete every finding without asking.
--verbose
Print each file as it is scanned.

Cheapest check first, stop at the first hit

Every file goes through these in order. Most files are cleared by the first step without ever being opened by a rule engine.

  1. Known malware hash

    A SHA-256 of the file is looked up in a sorted database that is memory-mapped, so a database of millions of hashes costs almost no RAM.

  2. YARA rules

    Executables, scripts, documents and archives are matched against compiled YARA-X rules, which describe malware by its patterns instead of its exact bytes. Your own rules go in a folder and are picked up on the next update.

  3. Heuristics (opt-in)

    A weak signal, reported as suspicious and never as proven malware: for example a high-entropy executable sitting in a temp folder. Off unless you pass --heuristics.

Light enough to forget about

ZengAV only uses resources while you run it.

  • No background processNo daemon, login item or scheduled task. It starts, scans, exits.
  • Half your cores, lowest priorityWorker threads are capped at half the processor, and the scan runs at the lowest CPU priority.
  • Files are streamedEach file is read in 64 KB pieces, so a 20 GB disk image costs the same memory as a text file.
  • Unchanged files are skippedAfter a clean scan, files with the same size and modified time are not read again until your signatures change.

What it will not do

A small tool should be clear about its edges.

  • It does not watch your computer. There is no real-time protection and no kernel driver. It finds what is on disk when you run it.
  • It is only as good as its signatures. It will not catch a brand-new threat that nobody has described yet. Treat it as a strong second opinion next to the protection your operating system already provides.
  • Malware hashes need a free key. abuse.ch, which publishes the hash list, requires each person to get their own free Auth-Key at auth.abuse.ch. Without one, ZengAV still uses YARA rules, but skips the hash feed.
  • It never deletes on its own. Deleting happens only when you answer d or pass --delete.
  • It sends nothing anywhere. The only network traffic is the update you ask for. There is no telemetry.
